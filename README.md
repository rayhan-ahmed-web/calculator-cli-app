# Calculator CLI App

Internship project for Elevate Labs — Task 1.

A simple command-line calculator built in Python.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Input validation for non-numeric values
- Division-by-zero protection
- Interactive loop until Exit
- Separate functions for each arithmetic operation

## Requirements

- Python 3.x
- Terminal / command prompt

## How to Run

```bash
python calculator.py
```

Or:

```bash
python3 calculator.py
```

## Example

```text
==================================
       CALCULATOR CLI APP
==================================

Choose an operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit
Enter your choice (1-5): 1
Enter first number: 12
Enter second number: 8
Result: 20
```
